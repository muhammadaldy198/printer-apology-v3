# printer-apology-v3

One-line apology note written by an office printer to the people who use it — entry for the make.fun bounty "The Printer Apology".

![reward](https://make.fun/badge/u-eager-stork-81-9647-the-printer-apology-60229153/muhammadaldy198/printer-apology-v3/reward.svg)

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Entry

> Correction: I've counted 96 love letters since February, jamming on your cheapest paper. I printed one for your wife.
